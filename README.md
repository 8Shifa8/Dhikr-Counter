# 🧮 Dhikr Counter (PyQt5)

A simple desktop counter app built using Python and PyQt5.  
You can increase the count or reset it with buttons.

---

## 🚀 Features

- ➕ Increase counter by 1
- 🔄 Reset counter to 0
- 🖥️ Simple GUI using PyQt5
- ⚡ Lightweight and fast

---

## 🛠️ Built With

- Python 🐍  
- PyQt5 (Qt for Python)
